# Preprint results

This directory contains the per-species outputs used for the CURIA preprint.

The full `hg38_vs_*` result directories are not stored in Git because of their size. 
The exact snapshot used for the preprint is archived on Zenodo.

- Zenodo record: `https://zenodo.org/records/21383175`
- DOI: `https://doi.org/10.5281/zenodo.21383175`
- Dataset version: `1.0`

To download and extract the results into this directory, run:

```bash
./download.sh
```

After extraction, the directory should contain:

```txt
hg38_vs_HLbalEde1/
hg38_vs_HLcamDro2/
hg38_vs_HLdidVir1/
hg38_vs_HLeleMax1/
hg38_vs_HLmanJav2/
hg38_vs_HLnotEug3/

hg38_vs_HLpteVam2/
hg38_vs_bosTau9/
hg38_vs_canFam5/
hg38_vs_dasNov3/

hg38_vs_mm39/
hg38_vs_monDom5/
hg38_vs_rheMac10/
```

These files correspond to the result snapshot described in the preprint. 
Newer dataset versions, if available, may contain additional species or corrected outputs.
